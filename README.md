# Приложение для анализа транзакций.

## Описание приложения
Приложение для анализа транзакций, которые находятся в Excel-файле. Приложение будет генерировать JSON-данные для веб-страниц, формировать Excel-отчеты, а также предоставлять другие сервисы.

## Возможности

### Страница «Главная» (`src/views.py::website`)

- **Динамическое приветствие** в зависимости от текущего времени суток
- **Сводка по банковским картам**:
  - Последние 4 цифры номера карты
  - Общая сумма расходов за период
  - Расчет кэшбэка (1 рубль на каждые 100 рублей расходов)
- **Топ-5 транзакций** по абсолютной величине суммы платежа
- **Актуальный курс валют** (USD, EUR → RUB) через внешнее API
- **Котировки акций** S&P500 (AAPL, AMZN, GOOGL, MSFT, TSLA) через внешнее API

### Сервисы (`src/services.py`)

- **Поиск операций** по описанию или категории
- Дополнительные примеры функциональности:
  - "Инвесткопилка"
  - Поиск телефонных номеров в транзакциях
  - Анализ переводов физическим лицам

### Отчёты (`src/reports.py`)

- **"Траты по категориям"** — анализ расходов по категориям за последние 3 месяца от указанной даты
- **"Траты по дням недели"** — статистика расходов в разрезе дней недели
- **"Траты в рабочий/выходной день"** — сравнение расходов по типам дней
- **Автосохранение результатов** — декоратор `save_report` автоматически сохраняет результаты отчётов в JSON-формате

## Требования

- **Python**: `>=3.11, <3.14`
- **Poetry**: для управления зависимостями
- **Основные библиотеки**:
  - `pandas` — работа с данными
  - `requests` — HTTP-запросы к API
  - `python-dotenv` — работа с переменными окружения
  - `openpyxl` — чтение Excel-файлов
  - *Опционально*: `xlrd==1.2.0` для поддержки старых .xls форматов

## Установка и настройка

1. **Клонируйте репозиторий и перейдите в директорию проекта**:
```
   git clone git@github.com:CyberLeo92/coursework_1.git
   cd <папка-проекта>
```

2. Установите зависимости через Poetry
```
poetry install
```

3. Настройте переменные окружения:
```
cp .env.example .env
```
Отредактируйте файл .env, указав ваши API-ключи 
(можно оставить пустыми — в тестовом окружении сетевые вызовы мокаются):
```
API_KEY_exchange=your_exchange_api_key
API_KEY_sp=your_twelvedata_api_key
```

Подготовьте данные:

Поместите файл с транзакциями в data/operations.xlsx

Ожидаемые столбцы (согласно ТЗ): Дата операции, Сумма платежа/Сумма операции, Номер карты, Категория, Описание и другие

Приложение автоматически преобразует даты и суммы к корректным типам данных

### Запуск
```
# Запуск демонстрационной версии (точка входа):

poetry run python -m src.main
```

#### Пример использования функционала "Главной страницы":
```
from src.views import website

greeting, cards, top, currency, stocks = website("2020-05-20 12:00:00")
# cards: [{"last_digits": "7197", "total_spent": 1234.56, "cashback": 12.35}, ...]
```


### Тестирование:
Запуск всех тестов:
```commandline
poetry run pytest -q
```

Для покрытия исключил точку входа `src/main.py` (см. `.coveragerc/pyproject.toml`).

### Логирование:

Приложение использует структурированное логирование. Лог-файлы сохраняются в директорию `log/`:

- `utils.log` — логи вспомогательных функций

- `views.log` — логи генерации представлений

- `reports.log` — логи построения отчётов

- `main.log` — логи точки входа

Конфигурация логирования находится в `src/logger.py`.
